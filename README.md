# Путевые заметки

Приложение для ведения дневника путешествий: поездки и заметки по дням.

## Назначение

Помогает путешественнику вести записи о поездках: хранить сведения о
маршрутах, фиксировать впечатления по дням и не терять их после поездки.

## Целевая аудитория

Путешественники, которые хотят вести дневник поездок: туристы,
любители походов и автостопа, travel-блогеры.

## Предметная область

Путешественник совершает поездки. Во время поездки он делает заметки
о конкретных днях: что увидел, где был, сколько потратил.
Заметка может быть сделана только на день, входящий в период поездки.

## Основные сущности

- поездка (маршрут, страна, даты начала и окончания);
- путешественник (автор заметок);
- заметка (запись о конкретном дне поездки).

## Основные функции

- расчёт длительности поездки в днях;
- расчёт среднего бюджета поездки на один день;
- проверка, входит ли выбранный день в период поездки;
- определение статуса дня: можно ли добавить заметку.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
