# Путевые заметки

Консольное приложение для ведения дневника путешествий: поездки и заметки
по дням.

## Возможности

- просмотр, поиск и сортировка поездок;
- проверка длительности поездки;
- проверка, можно ли добавить заметку на выбранный день;
- добавление заметок (одна заметка на один день поездки);
- архивирование заметок;
- добавление новых поездок;
- сохранение данных между запусками (JSON).

## Целевая аудитория

Путешественники, которые ведут дневник поездок.

## Структура проекта

- `main.py` — точка запуска и меню;
- `trips.py` — функции работы с поездками;
- `notes.py` — функции работы с заметками (в том числе
  `get_note_status()` из ПР1);
- `storage.py` — загрузка и сохранение данных в JSON;
- `utils.py` — безопасный ввод чисел и дат;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных

`data/trips.json` — список поездок:

```json
{"id": 1, "title": "Байкал", "country": "Россия",
 "start_date": "2026-07-10", "end_date": "2026-07-17"}
```

`data/notes.json` — список заметок:

```json
{"id": 1, "trip_id": 1, "note_date": "2026-07-12", "text": "..."}
```

В памяти поездки хранятся в словаре `{id: данные}`, заметки — в списке
словарей. Классы на этом этапе не используются.
